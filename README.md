# 📝 Gestionnaire de Tâches Avancé (Python)

Un mini‑projet Python permettant de gérer des tâches avec :
- priorité (basse / moyenne / haute)
- date de création automatique
- statut (en cours / terminé)
- tri par priorité ou par date
- sauvegarde dans un fichier JSON
- interface console simple et colorée

Ce projet est parfait pour apprendre :
- la programmation orientée objet (POO)
- la manipulation de fichiers JSON
- les exceptions
- les menus interactifs
- l’organisation d’un projet Python en modules

---

## 🚀 Fonctionnalités

### ✔️ Ajouter une tâche
- Titre  
- Description  
- Priorité  
- Date de création automatique  

### ✔️ Afficher les tâches
- Statut (terminée / non terminée)
- Priorité
- Date de création

### ✔️ Marquer une tâche comme faite

### ✔️ Supprimer une tâche

### ✔️ Trier les tâches
- Par priorité  
- Par date  

### ✔️ Sauvegarde automatique
Toutes les tâches sont enregistrées dans `taches.json`.
